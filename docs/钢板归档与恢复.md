# 钢板正式记录归档与恢复

质量工程师定稿时，系统把员工版 Excel、对应预览、记录快照、模板哈希和文件 SHA-256 一起存入数据库。系统在同一笔事务中保存签认及归档，归档失败时仍可回到草稿修改。正式下载、手机临时链接和断点续传均读取这份原件。

从旧版升级时，历史定稿可能只有签认数据和模板哈希。系统读取已登记的匹配模板，在首次打开旧定稿预览或下载时补档，并将来源标为“历史补档”。当原始模板缺失时，需要部长找到哈希匹配的原模板。补档能恢复已签认数据与原版式，无法证明与升级前某一次下载的文件逐字节相同。

## 备份与恢复演练

在项目目录打开 PowerShell，将下列路径替换为实际备份路径。每次备份和恢复都使用一个尚不存在的目录。备份内有员工账号数据、录音、归档文件和模板，应放在部长可访问的存储上。

```powershell
.\.venv-asr\Scripts\python.exe tools\steel_archive_admin.py backup --out D:\QC-Backup\before-upgrade
.\.venv-asr\Scripts\python.exe tools\steel_archive_admin.py verify --backup D:\QC-Backup\before-upgrade
.\.venv-asr\Scripts\python.exe tools\steel_archive_admin.py restore --backup D:\QC-Backup\before-upgrade --out D:\QC-Restore\inspection
```

脚本以 SQLite 在线备份接口取得一致的数据库副本，并复制录音、整机 PDF 和模板。若还要同时备份正在写入的录音或 PDF，可在停止服务后执行备份。校验包括文件清单、每个文件的 SHA-256、SQLite 完整性以及正式记录与归档内容的对应关系。恢复到新目录后，把同版本应用程序和依赖放入该目录，用恢复出的 `data` 和 `templates` 启动，抽查已知单据和实际下载文件。备份目录不含启动服务的证书、私钥或语音模型。

## 补存旧版定稿

先备份。下面的命令只处理尚无归档的定稿，输出未能处理的记录号与原因。已定稿的业务数据不会被改写。

```powershell
.\.venv-asr\Scripts\python.exe tools\steel_archive_admin.py backfill --db data\demo.db
.\.venv-asr\Scripts\python.exe tools\steel_archive_admin.py backfill --db data\demo.db --template D:\QC-Templates\old-steel.xlsx
```
